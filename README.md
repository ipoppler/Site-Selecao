Portal da Seleção | Site que mostra detalhes sobre a Seleção Brasileira de Futebol de 2026, como jogos ganhos, jogadores titulares e história sobre as seleções anteriores do Brasil.
- JavaScript, HTML, CSS, GitHub e Netlify
- Acessar o link a seguir para ver o site completo sem falhas: https://selecaobrasileira-isabella.netlify.app

***Justificação de Arquivos:***
### **- Pasta Fontes**
Pasta onde estão organizados todos os arquivos de fontes externas utilizadas no site.
### **- Pasta Imagens**
Pasta onde estão todas as imagens utilizadas para o site.
### **- Pasta css**
Onde está o CSS3 da seção "Hexa" do site.
### **- hexa.html**
Arquivo onde está a estrutura da seção "Hexa".
### **- index.html**
Estrutura do site em geral, que compõe a atividade principal.
### **- script.js**
Arquivo onde foram colocadas todas as animações e funções de JavaScript, conectadas tanto ao site completo da Seleção Brasileira tanto a seção "Hexa".
### **- style.css**
Arquivo onde a identidade visual do site principal está localizada. Não foi posta na pasta "css" pois haviam erros na reprodução da identidade visual, e portanto para resolvê-los, retiramos o CSS da pasta.
